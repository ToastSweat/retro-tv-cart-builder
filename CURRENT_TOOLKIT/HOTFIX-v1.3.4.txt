RETRO TV CART BUILDER v1.3.4
==============================

STALE REPLACEMENT SAFETY FIX
----------------------------
Review CSVs can retain a ReplacementAssetID if a replacement was selected and
the Action was later changed to NEEDS_CROP, NEEDS_CLIPPED, GOOD, BAD_AUDIO, etc.

Older Apply-RetroCartReview.ps1 versions would still honor that stale ID and
replace the clip even though the Action no longer requested replacement.

v1.3.4 only honors ReplacementAssetID when Action is one of:

  REPLACE_THIS_CART
  BAD_QUALITY
  DUPLICATE
  WRONG_ERA
  WRONG_NETWORK

For repair actions, stale replacement IDs are ignored with a warning.

This specifically makes the current NICK01-r004 review safe: slot
NICK01-BREAK-04-IN is NEEDS_CROP but still contains a stale replacement ID.
v1.3.4 will crop that clip rather than replacing it.
