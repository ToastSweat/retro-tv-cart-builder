RETRO TV CART BUILDER v1.2.0
==============================

NON-DESTRUCTIVE CROP SUPPORT
----------------------------
The review builder now runs FFmpeg cropdetect against multiple samples of each
uncropped source and reports a suggested baked-border crop when the result is
meaningful.

The source files are NEVER edited.

The reviewer now shows:
- Suggested crop: Left / Right / Top / Bottom
- approximate percentage of source frame removed
- "Use Suggested Crop" button
- manual Left / Right / Top / Bottom crop fields
- NEEDS_CROP review state

Workflow:
1. Rebuild/reopen the current review dashboard.
2. Select a clip with a thick baked-in border.
3. If the suggestion looks sensible, click "Use Suggested Crop".
   This fills the four crop fields and marks NEEDS_CROP.
4. Export Review CSV.
5. Apply the review to create the next cart revision.
6. Rebuild review. Only newly cropped/changed proxies are re-encoded.
7. Inspect the result and its neighboring boundaries.

Applied crop values become durable cart-manifest metadata and therefore remain
reproducible forever.

IMPORTANT:
cropdetect is a suggestion, not an automatic destructive action. Old TV sources
can contain intentional black frames/letterboxing/fades, so the human reviewer
still approves the crop.

CACHE BEHAVIOR
--------------
The actual encoding profile remains "review-v1". Unchanged, uncropped files
reuse the existing cache.

Only a clip whose trim/crop/source changed gets a new cache key.

GLOBAL SOURCE STATE
-------------------
A source marked NEEDS_CROP is conservatively removed from future automatic cart
selection until repaired/approved, just like NEEDS_CLIPPED.

OPEN CART CONVENIENCE
---------------------
The toolkit also now includes:

  .\Open-RetroCart.ps1 -CartID NICK01

It looks up the current revision and opens cart-review.html with Invoke-Item
-LiteralPath, so the [VIDEOS] brackets no longer cause Start-Process wildcard
nonsense.
