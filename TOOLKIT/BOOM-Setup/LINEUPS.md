# BOOM1 and BOOM2 lineups

Each cart groups three blocks per series. Each composite combines three complete shorts, without cropping. Quick Draw files already contain three segments and are used directly.

These are curated viewing lineups, not reconstructions of one broadcast date. The approved branding spans the toy era, including later clips. Commercials use general-audience 2000–2002-era material from the existing curated library; early Boomerang broadcast authenticity is not claimed.

No repeat-frequency ranking is claimed: archived schedules document some selections airing, but do not establish which were aired most often.
