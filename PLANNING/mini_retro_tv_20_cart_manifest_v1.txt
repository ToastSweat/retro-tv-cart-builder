MY MINI RETRO TV — 20 CART MIXTAPE PLAN v1
=============================================

Goal:
- 20 x 4 GB USB "carts"
- short FAT32-safe volume labels
- period-plausible station/block mixes
- recognizable, early-run, or iconic episodes rather than deep cuts
- no exact source file is used twice in this v1 plan

IMPORTANT:
- This is a CONTENT manifest, not a byte-perfect 4 GB fit manifest.
- Many source files are AVI/MKV/MPG, so they will need to be transcoded to MP4 for the Mini Retro TV.
- When we transcode, we can target a safe final cart size (for example ~3.4 GB) regardless of source sizes.
- PPG blocks use 2 source shorts; Dexter blocks use 3; Looney Tunes blocks use 3; Ren & Stimpy blocks use 2.
  Those groups are intended to become one continuous "half-hour-ish" output file during the build step.
