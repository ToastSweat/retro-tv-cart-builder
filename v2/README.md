# Retro TV Cart Builder v2 — 2.0.0-beta.1

Start Start-RetroTV.cmd. Open the existing project and saved lineup, then Studio. Finish Good + next and use BUILD FINAL LOCALLY or select/verify a drive and BUILD FINAL + COPY. No extra viewing or revision is required.

See ../docs/BUILD-AND-USB.md for installation, size fitting, outputs, safeguards and Windows acceptance checks. Original Studio controls/layout are retained. Jellyfin is excluded.

Development: Node >=22, npm ci, npm test, npm start. Dependencies remain pinned. FFmpeg/FFprobe are external tools; choose the working ffmpeg.exe in Studio and the machine preference is remembered. Media/project data belongs outside the application repository.
