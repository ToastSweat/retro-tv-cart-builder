RETRO TV CART BUILDER v1.3.0
==============================

THIS UPDATE IS BASED ON ACTUALLY WATCHING NICK01.

1) TRIM UX
----------
Entering a non-zero Trim Start or Trim End automatically changes an otherwise
GOOD/UNREVIEWED clip to:

  NEEDS_CLIPPED

The player now shows, live:

  12.43s elapsed · 17.62s remaining · 30.05s total

There are also two buttons:

  TRIM START = ELAPSED
  TRIM END = REMAINING

Pause on the exact frame you want and click the appropriate button.

2) TITLE-BASED TAG INFERENCE
----------------------------
Branding no longer depends only on manually-entered Notes.

Initialize-RetroCartLibrary.ps1 now derives InferredTags from:
- filename/title
- existing notes
- branding type
- show aliases found in cart configs
- phrases such as Up Next, Coming Up, Now Back, Back To, Then, etc.

This matters even for shows we do not own. A clip like:

  "Up Next Rocko's Modern Life, then My Brother and Me"

is recognized as PROGRAM_SPECIFIC and cannot masquerade as generic branding
just because nobody typed tags into its Notes field.

Run initialization once after installing v1.3.0 to populate InferredTags:

  .\Initialize-RetroCartLibrary.ps1

Durable BAD / NEEDS_CLIPPED / NEEDS_CROP / DUPLICATE state is preserved.

3) LEANER BROADCAST RECIPE
--------------------------
The old first-pass recipe was too busy.

Future NICK01-style planning now defaults to:

  SHOW
  1 COMMERCIAL
  1 matched/generic network transition
  NEXT SHOW

No automatic stack of:
  NEXT + BUMPER_OUT + multiple ads + BUMPER_IN + STING

NICK01 config now uses:
  AdsPerBreak = 1
  BreakStyle = LEAN
  UseMatchedNext = false
  no scheduled extra stings

4) THIN THE CART YOU ALREADY REVIEWED
-------------------------------------
You do NOT need to throw away your current review.

When you finish reviewing the current revision:
- mark replacements
- enter trims
- approve crop suggestions / enter crop values
- Export Review CSV

Then apply it with:

  .\Apply-RetroCartReview.ps1 `
      -CartID NICK01 `
      -ReviewCsv 'C:\path\to\your-review-state.csv' `
      -AutoReplace `
      -LeanBreaks

-LeanBreaks removes from the NEXT revision:
- all NEXT slots
- all BUMPER_OUT slots
- all STING slots
- extra ads after AD-01 in each break

It keeps:
- opening anchor
- every show
- one commercial per break
- one BUMPER_IN/network transition per break

Your trims, crops, replacements, history, and source-health findings are applied
at the same time.

If you marked a slot for replacement that LeanBreaks removes anyway, it will not
waste time demanding a replacement.

5) AFTER REVIEW: THE EXACT NEXT STEPS
-------------------------------------
A. Export the current Review CSV.

B. Create the corrected/thinner next revision:

  .\Apply-RetroCartReview.ps1 `
      -CartID NICK01 `
      -ReviewCsv 'C:\path\to\NICK01-r00X-review-state.csv' `
      -AutoReplace `
      -LeanBreaks

C. Rebuild the review:

  .\Build-RetroCartReview.ps1 -CartID NICK01

D. Open it:

  .\Open-RetroCart.ps1 -CartID NICK01

E. Spot-check the changed/repaired transitions. You do not need to rewatch every
unchanged episode unless you want to.

F. When happy:

  .\Build-RetroCartFinal.ps1 -CartID NICK01

Or build/copy/rename the physical cartridge in one go:

  .\Build-RetroCartFinal.ps1 -CartID NICK01 -TargetDrive 'E:\'

The USB gets the friendly volume label (NICK1) and shows live copy progress.
